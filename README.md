# IndustrialOps API

Plataforma web para gestión de operaciones industriales desarrollada con arquitectura Full Stack.

## Tecnologías utilizadas

### Backend
- FastAPI
- SQLAlchemy
- Alembic
- SQL Server
- JWT Authentication

### Frontend
- React
- Material UI
- React Router
- Axios

## Funcionalidades actuales
- CRUD de máquinas
- Validaciones y filtros
- Paginación
- Login con JWT
- Roles y rutas protegidas
- Integración frontend/backend mediante API REST
